# Proposal

## Why

하루를 길게 쓰는 일기는 꾸준히 이어 가기 어렵다. 한 줄만 빠르게 남기고 최근 기록을 바로 훑어볼 수 있는 가벼운 다이어리가 필요하다. 이 프로젝트에는 아직 아무 기능도 없으므로, 다이어리의 핵심인 "쓰기"와 "보기"를 첫 변경으로 만든다.

## What Changes

- 화면 상단에 오늘 날짜를 `YYYY-MM-DD` 형식(예: `2026-12-31`)으로 자동 표시한다. 날짜는 사용자 기기의 로컬 시간 기준이다.
- 한 줄 입력창과 저장 버튼을 제공한다. Enter 키로도 저장할 수 있다.
- 같은 날 여러 번 작성할 수 있으며, 각 기록에는 작성 날짜와 시간(`HH:mm`)이 함께 저장된다.
- 빈 입력이나 공백만 있는 입력은 저장하지 않고 경고 메시지를 보여 준다. 입력은 최대 100자로 제한한다.
- 기록은 브라우저 `localStorage`에 저장되어 새로고침 후에도 유지된다. 저장에 실패하면 앱이 멈추지 않고 안내 메시지를 보여 준다.
- 저장된 기록을 최신순으로 목록에 보여 준다. 목록 영역은 약 5개 높이로 고정하고, 기록이 그보다 많으면 영역 안에서 스크롤한다.
- 기술 스택은 Vanilla JS, Tailwind CSS(CDN), `localStorage`이며 빌드 단계나 서버가 없다.

범위 밖(이번 변경에서 하지 않음):

- 기록 수정·삭제
- 검색, 필터, 캘린더 보기
- 여러 기기 간 동기화, 로그인, 서버 저장

## Capabilities

### New Capabilities
- `diary-entries`: 한 줄 기록을 작성하고 저장하며, 저장된 기록을 최신순 목록으로 보여 주는 다이어리의 핵심 동작

### Modified Capabilities
(없음)

## Impact

- 새 파일: 정적 웹 페이지(`index.html`)와 앱 스크립트(JS). 기존 코드는 없다.
- 외부 의존성: Tailwind CSS Play CDN 스크립트(네트워크 연결 필요).
- 데이터: 브라우저 `localStorage`에 키 하나로 기록 배열을 저장한다. 다른 기기·브라우저와 공유되지 않는다.
